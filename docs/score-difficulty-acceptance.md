# 记分、难度、音乐与美术：实施前检查

难度：轻松4×4（8对，各类1至2件）、标准6×6（18对，各类3件）、挑战6×8（24对，各类4件）。所有难度都不限时；难度由牌数和查找范围区分，六种素材保留，任一档均足够完成五位拼贴。

记分：每对轻松50/标准100/挑战150分；连续正确配对从第二对起每对额外10分，最高额外50分；错误配对、使用提示或自动重排中断连续奖励，同格取消不中断。提示不扣已有分，不额外发分；无计时连击。完成时加该难度基础分两倍。最高分按难度本地保存，不进入作品画面。

修改新规则实现前列出的失败场景：
- 4列和6列坐标转换、外圈与边界均正确；三个难度各三种布局能清完，库存按难度守恒；有界重排不改数量。
- 连续奖励不越界，误配与提示重置，不因取消、刷新、同对重复点击增分；清盘加分只能一次。
- 旧v2存档以标准难度继续，历史已消对按基础分初始化（不补算不存在的连续奖励）；不能丢棋盘和手账。
- 本地最高分按难度隔离；恢复、重开、看旧作品不重复发分。损坏分数记录应拒绝，不因NaN污染存档。
- 音乐默认关闭，按钮明确显示开关；只有用户主动开启才播放，后台暂停，恢复失败可再次开启；断音不影响游戏。
- 原创配乐由允许发布用途的本地模型生成，无歌手/作品模仿、无参考歌曲；记录权重版本、许可、提示词、种子及处理步骤。
- 320/375/390/430宽度、各难度棋盘格≥44像素；挑战可正常竖向滚动，选择不能把页面滚回顶部。
- 浏览器完整流程留截图与报告；配乐文件静态包内，失败可关闭，不使用联网或模型推理运行时。
