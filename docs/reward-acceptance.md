# 0.8.0 直接发卡（实现前）

通关后直接展示并收藏一张卡，无选物、搭配、写字、领取确认流程。保留保存、分享、再玩。每张卡根据本局固定id生成主题，刷新不重抽。

等级按绝对分数，单调递增：元气0起、闪亮700起、珍藏2400起、梦幻4300起、典藏4800起。轻松500–750、标准2000–2750、挑战3900–4950（不改变计分）。每局一张，最近12张收藏。

实现前失败场景：
- 最后一对后仍停在编辑器/需要额外点击；卡图与页面等级或分数不一致。
- 边界690/700、2390/2400、4290/4300、4790/4800等级算错；重开/刷新换主题、重复收藏或重复加分。
- 存档在最后一对动画中、已通关棋盘、旧studio阶段：恢复后应直接发卡；旧result和旧收藏仍能查看。
- 新result允许空slots，但未通关不允许进入result；非法奖励记录不得破坏启动。
- 新局重置分数，保留最高分/收藏/音效偏好。查看旧卡不覆盖当前局。
- 卡片缩放在320/390/430宽不横向溢出，按钮不小于44px；无绘制图失败/中文溢出。
- 相册/笔记失败不丢卡；不可用时禁用，无额外网络或文件类型。

验收采用浏览器UI整局、隔离旧存档和边界回归，保存JSON及截图；普通浏览器不替代平台模拟器及Android/iOS真机验收。
