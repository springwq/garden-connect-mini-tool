# 历史路线方案的实现前验收场景

新版：风物折页。按四邻接格依次收集线索图章，六轮后制作五图章明信片。

- 三套固定种子中每轮线索可解；相邻、不能重复经过、顺序匹配；错误点击不发奖励。
- 撤销与提示不发奖励；末步快速重复点击不能跨轮奖励；后台不自动推进。
- 六轮奖励与实际路线一致，五个印章位置消耗与退回守恒，数量不足不能放入。
- 游戏、搭配、祝福语可恢复；损坏存档明确提示，合法旧作品尽量保留；存储失败不宣称已保存。
- 作品为1080×1440；20个Unicode字符；输入仅按文本绘制；最近3张按配方重绘。
- 保存与分享需主动点击；接口缺失/拒绝/导出失败保留配方；重复导出只有一个任务。
- 320/375/390/430宽度不横滚，触控目标至少44像素，键盘及减少动画可用。
- 普通浏览器只做实现回归；最终需平台模拟器、Android/iOS真机验证和实际导出图片。
