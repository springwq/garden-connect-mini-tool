# 0.7.1 音频验收（实现前）

已确认：用户在小红书手机预览中听到独立检测页的单音、消除声、旋律。未确认：系统类型、完整版双端兼容、音质偏好。

必须覆盖的失败情形：
- 无 AudioContext、创建或 resume 失败：提示一次，继续游戏，按钮不假装播放。
- 首次进入不自动发声；配乐仅通过用户动作启动；音效默认开，可单独关闭并保存。
- 错配无声；普通消除、连消、高连消、通关分别使用不同旋律。
- 快速开关、异步 resume 晚到，不得造成关闭后重播；重复开启不得叠加循环。
- 关闭音效不停止配乐，关闭配乐不禁用音效；切后台停止全部声音，回前台不自动发声。
- 循环连续、节点及时释放；调度失败需停止并恢复按钮，不得无限重复报错。
- 存档、计分、收藏卡不受影响。音乐片段为原创程序谱曲，不声称来自本地模型。
- ZIP 只包含平台允许扩展名，遗留 MP3 不进入包；仍保留模型源文件。

验证：真实浏览器 UI 回归及可重复报告；平台接受同一 ZIP 后提供二维码。浏览器检查不替代完整游戏的 Android / iOS 真机验收。
