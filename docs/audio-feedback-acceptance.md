# 消除音效与新配乐验收（实施前）

风险与检查：

- 配乐关闭时成功配对仍应触发音效；两套开关独立。
- 音效默认开启，但只在用户消除成功的操作中播放，首页加载不发声。
- 同格取消、错配、提示不能播放成功音效；成功配对只触发一次。
- 连续配对越多使用更亮的音阶；通关只播通关旋律，不叠加多个成功音轨。
- 连点、关音效、页面隐藏时停止现有音效；延迟的play Promise不能在关闭后恢复播放。
- 刷新后恢复音效偏好；旧存档缺少字段时默认开启，不破坏棋盘和最高分。
- 音频缺失或自动播放限制不阻塞计分、消除和通关；按钮可再次开启重试。
- 配乐与音效均本地文件，没有在线请求、WebAudio或运行时合成。静音控制保留中文无障碍名称。
- 本地浏览器记录成功配对后的audio currentTime、暂停与开关状态；真实移动端音频延迟、混音体验和后台行为仍需真机验证。
